## When Sage Intacct fits

Sage Intacct suits Sage 200 users whose main need is financial: consolidating several companies across currencies, billing subscriptions, recognising revenue or accounting for projects. It is cloud-only software, updated by Sage, so it also suits businesses that want to stop running their own servers.

## When Sage X3 fits

Sage X3 suits Sage 200 users whose operations have grown: more stock, several warehouses, lot or serial traceability, manufacturing, or trading in several countries. It runs finance, supply chain and production in one system, and can run as SaaS, in a private cloud or on-premise.

## Data migration choices

Migration scope affects cost and timeline. Agree it before you ask for quotes:

- **Balances only:** the smallest scope.
- **Balances plus summarised history:** gives year-on-year comparisons in the new system.
- **Detailed history:** the largest scope; worth it only where there is a clear reporting or compliance need.

## Timeline

Mysoft's published view is that an average Sage Intacct project costs less than an average Sage X3 project because it is faster to deliver. For Sage X3, Mysoft publishes three delivery options: 80 service days over six calendar months (Kickstart, which excludes manufacturing), 110 service days over nine months, and 140 service days over twelve months.
